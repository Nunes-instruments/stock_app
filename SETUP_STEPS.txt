NUNES STOCK v3.2.3 - PORT 5055 SETUP

MAIN SERVER PC
1. Extract the ZIP.
2. Right-click RUN_THIS_5055_MAIN_SERVER_SETUP.bat -> Run as administrator.
3. Existing v2.5.2 port 5000 remains untouched.
4. New v3 installs to C:\NunesStockV31\app.
5. New v3 data uses C:\ProgramData\NunesStockV31\data.
6. New server URL: http://127.0.0.1:5055
7. Staff URL: http://<MAIN-SERVER-IP>:5055

STAFF PC
1. Extract the client package or this package.
2. Run SETUP_STAFF_PC.bat.
3. Enter the MAIN SERVER IP only.
4. A NUNES Stock V3 desktop shortcut is created.

OWNER PC
1. Run SETUP_OWNER_PC.bat.
2. Enter the MAIN SERVER IP only.

IMPORTANT
The old 5000 server and new 5055 server have separate data after the first snapshot. Do not make production stock changes in both at the same time.
