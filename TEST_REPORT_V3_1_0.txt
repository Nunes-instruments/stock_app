IMPORTANT ENVIRONMENT LIMITATIONS
=================================
1. The exact Flask/Waitress HTTP preflight could not be executed inside the build container because Flask/Waitress are not installed there and the container has no package-download access. The Windows installer installs requirements_portable.txt first and then runs scripts/preflight.py before it creates/starts the production service. A failed preflight stops setup before startup.
2. Windows PowerShell / Task Scheduler / Firewall / .lnk creation cannot be executed in this Linux build container. The scripts were reviewed and their launchers were hardened to preserve failure exit codes, but the real Windows setup must still complete its own preflight on the target server PC.
