ENVIRONMENT LIMITATION
The current execution environment does not have Flask/Waitress available and cannot download packages due network/DNS restrictions, so the Windows HTTP startup and Task Scheduler behavior cannot be physically executed here. The Windows installer runs dependency installation and production preflight on the target PC before declaring the server online.

GITHUB CONNECTOR
The repository was read successfully through the connected GitHub account, but write operations return GitHub API 403 "Resource not accessible by integration". Therefore this package includes PUBLISH_TO_GITHUB.bat to perform a normal authenticated Git push from the user's Windows PC. No force push is used.
