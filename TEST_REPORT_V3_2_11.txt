That preflight additionally checks:

- archive/restore + history preservation
- Shelf Rack attach/move/remove without quantity changes

- dashboard/current-stock/add-stock/import/history/storage routes
- protected Rack/3D hashes

CLIENT UPDATE MODEL
-------------------
Staff/Owner PCs do not contain application code or databases.
The desktop shortcut opens the main server URL on port 5055.
Therefore future code releases are delivered from the server immediately.
The browser polls /api/system/state every 5 seconds:
- idle read pages reload automatically when VERSION changes
- active entry/edit pages show a reload notice to avoid losing unsaved work

LIMITATION OF THIS BUILD ENVIRONMENT
------------------------------------
Flask/Waitress are not installed in this Linux packaging environment, so the full Flask HTTP test-client preflight is not marked as executed here. The live Windows updater executes that preflight using the already-installed NUNES runtime before making live changes.
